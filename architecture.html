システムアーキテクチャ

本Webサイトを支えるサーバーレスインフラとIaC（Terraform）の取り組み

インフラ構成図

本サイトは、高パフォーマンス・高セキュリティ・低コストを実現するために、AWSのサーバーレスアーキテクチャを採用しています。

[ ユーザー (ブラウザ) ]
       │
       ▼ (HTTPS / CDN)
[ CloudFront ]
       │
       ├─► [ S3 ] (静的コンテンツホスティング)
       │
       └─► [ API Gateway ] ──► [ Lambda ] ──► [ SES ] (メール送信)
                                   ▲
                                   └─ (すべて Terraform で管理)

採用リソースと選定理由

1. Amazon S3 & CloudFront

静的ファイル（HTML/CSS/JS）をS3で保持し、CloudFrontを通じて世界中に高速配信しています。サーバーの管理が不要で、高い可用性とセキュリティを両立しています。

2. API Gateway & AWS Lambda

お問い合わせフォームのバックエンド処理には、完全サーバーレスな構成を採用。リクエストが発生した瞬間のみ実行されるため、24時間無駄なサーバーコストが発生しません。

3. Amazon SES (Simple Email Service)

フォームから送信されたお問い合わせを安全かつ確実に指定のメールアドレスへ通知・転送します。

4. Terraform による IaC (Infrastructure as Code)

すべてのインフラ構成をコード化して管理。構築手順の自動化、再現性の確保、バージョン管理を実現しています。
